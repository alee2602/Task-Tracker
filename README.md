# Task Tracker

![CI](https://github.com/alee2602/Task-Tracker/actions/workflows/tests.yml/badge.svg)

Gestor de tareas por línea de comandos. Proyecto práctico para aprender
metodología de desarrollo asistido por IA (specs, decisiones, planes, ciclos trazables).

## Metodología

Ver [CLAUDE.md](CLAUDE.md) para el flujo de trabajo completo.

- `specs/` — qué se construye y por qué
- `decisions/` — decisiones técnicas registradas (ADRs)
- `plans/` — cómo se implementa cada spec
- `src/` — código
- `tests/` — tests
